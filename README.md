Ridge Runner — Alpine Courier: fly the Kestrel K-9 bush plane through an alpine valley. Three missions — thread 8 glowing rings, land a medicine crate on the Eagle's Nest strip, or rescue a stranded hiker in a gusting storm — with fuel to manage, wind to fight, and a landing that has to be gentle. Chase view over recognisable terrain, lit instruments (airspeed, altitude, heading, attitude, radar), and a HUD that tells you when you are about to stall.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Keyboard: W/S throttle, arrow keys pitch & bank, SPACE airbrake, G gear, F flaps, P pause, R restart. Mouse works on the title-screen missions and the throttle slider.
